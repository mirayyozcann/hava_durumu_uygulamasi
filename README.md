# 🌤️ Python & Tkinter Hava Durumu Takip Uygulaması

Python ve Tkinter kullanılarak geliştirilmiş, anlık hava durumu verilerini çeken ve Matplotlib ile sıcaklık-nem değişimlerini grafiksel olarak görselleştiren masaüstü uygulamasıdır.

## 🚀 Özellikler

- **Anlık Hava Durumu:** Şehir seçimine göre güncel sıcaklık ve nem bilgilerini görüntüleme.
- **Grafiksel Arayüz (Data Visualization):** Matplotlib entegrasyonu ile 24 saatlik sıcaklık ve nem değişim trendlerini grafik üstünde analitik olarak inceleme.
- **Güvenli Mimarisi:** API anahtarları kaynak kodundan izole edilerek güvenli bir şekilde yönetilmektedir.
- **Kullanıcı Dostu Arayüz:** Tkinter ile tasarlanmış sade ve işlevsel masaüstü deneyimi.

## 🛠️ Kullanılan Teknolojiler ve Kütüphaneler

- **Python** (Programlama Dili)
- **Tkinter** (Arayüz / GUI)
- **Matplotlib** (Veri Görselleştirme ve Grafik Çizimi)
- **Requests** (API İstekleri)
- **SQLite** (Veri Yönetimi)
